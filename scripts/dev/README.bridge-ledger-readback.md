# AI Task Hub DEV readback deployment audit (non-mutating)

The PR #155 endpoint is a **read-only draft**. The current live DEV app must not be assumed to contain it because PR tests pass. Before activating any DEV rollout, record the current image/tag and rollback plan, review the authenticated bearer readback permissions, and verify the newly deployed code in isolation. The AI Core client must remain opt-in and fail-closed.

From the VPS host, run `node scripts/dev/bridge-ledger-readback-runtime-preflight.mjs` from this repository checkout. It inspects only Docker container `ai-task-development`; it does **not** read token values, modify env, call worker endpoints, restart containers or query database rows. It returns process exit `3` and `BLOCKED` until both the route is present in the runtime bundle and `AI_TASK_BRIDGE_READBACK_ENABLED=true`. A deployed route with the flag off is expected to be blocked. A ready result **still is not an authenticated readback** and cannot authorize GPT02 signing, grants, dispatch or job close.

Observed baseline on 2026-11-08 VPS `srv1792369`: `ai-task-development` image `ai-task-hub:dev-timeline-154-safe-8a4b2ee` healthy, route not detected, flag not enabled. Anonymous HTTPS request returned `403`; this is only an unauthenticated proxy observation, **not** proof of route availability or authorization. The production container was untouched. Do not enable the flag on the old image and claim a passing drill.

After reviewed **DEV-only** rollout and rollback preparation, rerun the preflight, then perform an authenticated **read-only** GET for a real DEV command using a scoped service credential from a protected runtime. Verify the receiving `AI_CORE`, `bridge-command:<uuid>`, default tenant, `passiveLedger` boolean, exact `timeline.commandId` and allowed worker, plus all authority-denial flags. Never log the bearer credential. The source and receiver records must be compared independently before marking *identity observation*; never infer native GPT02 completion or grant permission. PROD promotion remains separately gated.
