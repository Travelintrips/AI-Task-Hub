---
name: AI Task Hub public URL
description: Canonical base URL rules for customer-facing links generated by AI Task Hub.
---

All customer-facing AI Task Hub links must use the centralized public URL resolver. Production is fixed to `https://ai-task.travelintrips.co.id`; development must use the current `REPLIT_DEV_DOMAIN` runtime value, even when another Replit domain is also present.

**Why:** A WhatsApp mini-form link previously exposed a generated Replit deployment hostname, which can differ from the stable public domain and make customer messages unreliable.

**How to apply:** Add new public-link features through the resolver/helper in `artifacts/api-server/src/config.ts`; do not read `FRONTEND_URL`, `REPLIT_DOMAINS`, or construct a feature-specific public origin. Keep `PUBLIC_APP_BASE_URL` set to the canonical production domain.
