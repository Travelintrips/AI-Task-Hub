Create a new module called AI Task Center integrated into the existing system without replacing or deleting current features.

Existing modules such as customer order, quotation, shipment, trucking, warehouse, vendor, finance, RFQ, and BizPortal must remain active and connected.

Purpose:
AI Task Center acts as an AI Operational Brain that handles:
- WhatsApp inquiries
- AI intent detection
- AI task creation
- document upload
- OCR and text extraction
- document audit
- workflow routing
- team assignment
- WhatsApp notifications
- mini task forms
- customer missing data forms
- operational timeline
- customer context memory

Use:
- React frontend
- Tailwind
- Node.js
- Express
- Supabase database
- Supabase Storage
- OpenAI API
- WhatsApp Gateway webhook integration

Create clean, modular, scalable, mobile responsive architecture.

==================================================
WHATSAPP WEBHOOK
==================================================

Create:
POST /api/whatsapp/webhook

Function:
1. Receive incoming WhatsApp messages.
2. Save sender, message, attachment, raw payload.
3. Support:
   - text
   - image
   - PDF
   - Excel
   - Word
   - voice note placeholder
4. Save all messages to whatsapp_messages.
5. Trigger AI intent detection.
6. Do not block webhook if AI fails.

- customer sentiment

- suggested team

- General Inquiry

Priority logic:

==================================================
IMPORT LOGIC
==================================================

If customer says:
- import machine from China
- import barang
- customs clearance
- mesin dari China

Then:
category = Import
division = Import / Customs
needs_document_audit = true
needs_admin_review = true

AI must ask for:
1. Commercial Invoice
2. Packing List
3. HS Code
4. Product photo/catalog
5. Supplier name
6. Origin country/city
7. Port of loading
8. Port of discharge
9. Delivery city
10. Gross weight
11. Net weight
12. Dimensions
13. Incoterm
14. Importer name
15. NIB/API
16. Machine condition (new or used)

If missing data exists:
generate polite Indonesian WhatsApp reply asking only missing items.
