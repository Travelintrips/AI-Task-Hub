SPRINT 5B — VENDOR MEMORY CENTER

Customer Memory Center sudah selesai dan tervalidasi.

Sekarang bangun Vendor Memory Center dengan prinsip yang sama:

* additive only
* tidak mengubah workflow existing
* tidak mengubah source of truth
* semua memory harus berasal dari data operasional yang sudah ada

====================================================
OBJECTIVE
=========

AI harus dapat menjawab:

* vendor mana paling cocok untuk pekerjaan tertentu
* vendor mana paling murah
* vendor mana paling cepat
* vendor mana paling responsif
* vendor mana paling sering menang RFQ
* vendor mana paling cocok untuk route tertentu
* vendor mana yang berisiko tinggi
* vendor mana yang dokumennya sudah kadaluarsa

Vendor Memory harus digunakan oleh:

* RFQ
* Vendor Comparison
* Quotation Engine
* AI Task Detail
* Dispatcher
* Future Purchasing Intelligence
