====================================================
SECTION 2 — INTAKE MODE CLASSIFICATION
======================================

For every intent classify:

conversation
mini_form
hybrid

Rules:

CONVERSATION

Use when:

* ≤ 5 required fields
* no document required
* user expects quick answer

Examples:

cash_advance
invoice_request
payment_confirmation
customer_data_update
simple complaint

MINI_FORM

Use when:

* many fields
* structured process
* multiple documents
* user normally fills a form

Examples:

import_inquiry
export_inquiry
vendor_registration
tenant_rental
sport_center_booking

HYBRID

Use when:

* AI should ask first
* then send form only if needed

Examples:

trucking
air_freight_inquiry
sea_freight_inquiry
customs_clearance
ppjk_service
fleet_repair
damaged_goods_complaint
delivery_delay_complaint
