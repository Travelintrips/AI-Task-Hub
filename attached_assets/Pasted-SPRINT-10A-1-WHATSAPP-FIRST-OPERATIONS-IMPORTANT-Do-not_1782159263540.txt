SPRINT 10A-1 — WHATSAPP FIRST OPERATIONS

IMPORTANT

Do not replace existing portals.

Do not replace Conversation Intake Engine.

Do not replace Mini Form Router.

Goal:

Allow Driver, Vendor, Customer, Supervisor, and Executive
to perform daily operations directly from WhatsApp.

Portal remains available.

WhatsApp becomes primary interaction channel.

====================================================

====================================================

====================================================
PHASE 2 — CUSTOMER COMMANDS
====================================================

Implement:

STATUS [ORDER]

Example:

STATUS CST-2026-001

Return:

Order Status
Current Stage
Last Update
PIC
Invoice Status
Payment Status

----------------------------------------------------

DOCS [ORDER]

Return:

Required Documents
Uploaded Documents
Missing Documents

----------------------------------------------------

HELP

Return available commands.

====================================================
PHASE 3 — DRIVER COMMANDS
====================================================

Implement:

BBM [PLAT] [LITER] [ODOMETER]

Example:

BBM B1234XYZ 40 125000

System:

Create fuel log
Run anomaly detection
Return KM/L benchmark

----------------------------------------------------

RUSAK [PLAT] [DESKRIPSI]

Example:

RUSAK B1234XYZ Rem belakang bunyi

System:

Create maintenance request
Create AI task
Notify supervisor

----------------------------------------------------

POSISI [PLAT] [LOKASI]

Example:

POSISI B1234XYZ Cikampek KM72

System:

Append fleet utilization note

----------------------------------------------------

HELP DRIVER
