====================================================

All tables must include:

- created_at

- indexes on company_id, fleet_unit_id, date fields

====================================================
B. FUEL INTELLIGENCE
====================================================

Implement:

POST /api/fleet/fuel
GET  /api/fleet/fuel
GET  /api/fleet/fuel/analytics
GET  /api/fleet/fuel/anomalies
POST /api/fleet/fuel/benchmarks

Logic:
- calculate km_since_last_fill
- calculate km_per_liter
- compare with fleet_fuel_benchmarks
- flag anomaly if below tolerance
- write audit log fleet.fuel.logged
- write audit log fleet.fuel.anomaly_flagged
- do not create expense automatically

Anomaly examples:
- KM/L below benchmark tolerance
- odometer regression
- liters unusually high
- duplicate fuel entry same day/unit/amount

====================================================
C. TIRE LIFECYCLE
====================================================

Implement:

POST /api/fleet/tires
GET  /api/fleet/tires
PATCH /api/fleet/tires/:id
POST /api/fleet/tires/rotation
GET  /api/fleet/tires/lifecycle

Logic:
- track tire serial, position, install date, install odometer
- track expected life km
- calculate used km
- calculate remaining km
- flag worn tires
- track tire rotations
- write audit logs:
  fleet.tire.installed
  fleet.tire.updated
  fleet.tire.rotated
  fleet.tire.replaced
