SPRINT 9D — CONVERSATION TEST SUITE & AI QUALITY GATE

Sprint 9A, 9B, and 9C are planned.

Now build a test and quality gate layer to ensure AI conversations behave correctly before production use.

Goal:
Every important WhatsApp scenario must be tested automatically:
- AI asks missing data first
- AI sends correct mini form when needed
- AI validates documents
- AI does not create task too early
- AI creates task only when data is complete
- AI hands off to admin when confidence is low or risk is high

====================================================
B. TEST RUNNER
====================================================

Create:

artifacts/api-server/src/lib/conversation-test-runner.ts

Responsibilities:

1. Load active test cases.
2. Simulate incoming WhatsApp messages.
3. Run through IntentEngine + IntakeEngine.
4. Do not send real WhatsApp.
5. Do not create real customer-facing task unless test mode.
6. Compare actual behavior vs expected_behavior.
7. Save test results.
8. Calculate pass rate.

Test mode:
- use sandbox phone number
- mark all created tasks test_mode=true if any task is created
- no Fonnte sending
- no admin notification

====================================================
F. QUALITY GATE
====================================================

Create quality gate rules:

- pass_rate must be >= 90%
- no critical scenario may fail
- no task may be created before required fields complete
- no auto-approval allowed
- all low-confidence scenarios must ask clarification or handoff
- all mini form intents must send correct mini form type

If gate fails:
- status = failed
- block production AI mode
- show failed cases

If gate passes:
- status = passed
- production AI mode allowed

====================================================
G. PRODUCTION AI MODE SWITCH
====================================================

Add setting:

company_settings.ai_production_mode

Allowed:
- off
- test
- production

Rules:

off:
- AI does not reply automatically

test:
- AI runs but does not send WA or create live tasks

production:
- AI sends WA and creates tasks only if latest quality gate passed
