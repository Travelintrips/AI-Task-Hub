Sprint 9A and 9B are validated.

Goal:
AI must validate uploaded documents from WhatsApp, mini forms, tasks, fleet, vendor, and purchasing flows.

====================================================
C. DOCUMENT VALIDATION ENGINE
====================================================

Create or complete:

src/lib/document-validation-engine.ts

Responsibilities:

1. identify document type
2. load rule by document_type + intent_code
3. extract fields using OpenAI vision/OCR
4. compare extracted_fields vs required_fields
5. calculate missing_fields
6. assign validation_status
7. save document_intake_audits
8. return result

Rules:

- confidence < 0.65 → needs_review
- required fields missing → incomplete
- wrong document type → invalid
- all required fields found → valid

====================================================
D. MINI FORM INTEGRATION
====================================================

When mini form includes file upload:

1. Save file
2. Call DocumentValidationEngine
3. Store audit id in uploaded_documents
4. Update conversation_intake_sessions.uploaded_documents
5. Recalculate missing documents
6. If documents incomplete:
   - keep session active
   - send WhatsApp reply asking missing documents
7. If documents valid and fields complete:
   - create ai_task
   - attach document audit results
   - mark session submitted

====================================================
E. WHATSAPP DOCUMENT INTEGRATION
====================================================

When WA receives image/document:

1. Check active intake session
2. Identify expected document types from session
3. Validate uploaded document
4. Update session uploaded_documents
5. Reply to user:

Valid:
"Dokumen {document_type} sudah diterima dan valid."

Incomplete:
"Dokumen {document_type} sudah diterima, tetapi data berikut belum terlihat: {missing_fields}. Mohon kirim ulang atau lengkapi."

Invalid:
"Dokumen yang dikirim belum sesuai dengan {document_type}. Mohon kirim dokumen yang benar."

Needs review:
"Dokumen sudah diterima dan akan dicek manual oleh admin."
